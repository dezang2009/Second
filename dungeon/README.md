# 심연의 계단

텍스트로 즐기는 던전 탐험 RPG. 지하 10층, 심연의 바닥에 잠든 군주를 쓰러뜨리면 승리합니다. 쓰러지면 처음부터 다시 시작합니다(로그라이크).

## 플레이

- **직업 3종**: 전사(튼튼함) · 마법사(강한 주문, 마나 관리) · 도적(치명타·회피, 함정·미믹 감지). 레벨 4에 두 번째 기술을 배웁니다.
- **탐험**: 층마다 5×5 지도에 방이 무작위로 만들어집니다. 오른쪽 위 미니맵(● 나, ▼ 계단, ! 괴물, ◆ 상자, $ 상인, ✦ 제단, ☠ 보스).
- **방**: 괴물, 보물 상자(가끔 미믹), 함정, 축복의 제단(체력·힘·지혜 중 택1), 떠돌이 상인, 계단.
- **전투**: 공격 · 기술 2개 · 방어(피해 60% 감소, 마나 +2) · 물약 · 에테르 · 도망. 보스가 힘을 모으면(⚠) 방어하세요.
- **보스**: 5층 고블린 왕 그락, 10층 심연의 군주(체력이 절반 아래로 떨어지면 공격력이 오름).
- 층마다 한 번 **휴식** 가능(30% 확률로 기습).
- 버튼 대신 입력창에 `북`, `공격`, `물약`, 번호(`1`) 같은 명령을 적어도 되고, PC에서는 방향키로 이동합니다.
- 매 행동마다 자동 저장되고, 명예의 전당에 상위 10개 기록이 남습니다.

## 실행

- 브라우저: `web/index.html`을 열면 됩니다.
- 안드로이드 APK (Android 8.0 이상):

```bash
ANDROID_BUILD_TOOLS=<build-tools 경로> ANDROID_JAR=<platforms/android-XX/android.jar> dungeon/build_apk.sh
```

`dungeon/dist/AbyssStairs.apk`가 만들어집니다. Gradle 없이 aapt2·d8·zipalign·apksigner만 씁니다. 서명 키(`android/release.keystore`)는 처음 빌드할 때 만들어지고 저장소에는 올리지 않습니다. 같은 키로 서명해야 업데이트 설치가 되니 보관하세요.

## 구조

| 경로 | 내용 |
| --- | --- |
| `web/game.js` | 게임 전체 (데이터, 층 생성, 전투, 화면) |
| `web/index.html`, `web/style.css` | 화면 |
| `android/` | WebView 앱 껍데기 (매니페스트, 액티비티, 아이콘) |
| `build_apk.sh` | APK 빌드 스크립트 |
