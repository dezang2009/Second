# 킥오프 매니저

실제 선수단으로 즐기는 모바일 축구 감독 게임입니다. 22명이 움직이는 **2D 실시간 경기 엔진** 위에서 전술과 교체로 경기 흐름을 바꿀 수 있어요.

## 실제 데이터

- **6개 리그, 108개 구단, 약 2,950명**: 프리미어리그, 라리가, 분데스리가, 세리에 A, 리그 1, K리그 1 (2026/27 시즌 선수단)
- [트랜스퍼마크트](https://www.transfermarkt.co.kr)에서 소속팀, 세부 포지션, 나이, 국적, 키, 계약 기간, 시장 가치, 홈구장과 수용 인원, 선수 사진, 구단 엠블럼을 가져옵니다.
- 모든 선수 이름은 한글로 표시합니다. 한국 선수는 트랜스퍼마크트 프로필의 본국 이름, 외국 선수는 위키데이터의 한국어 표기(`data/names_wikidata.json`, 약 1,280명)를 쓰고, 나머지 약 1,390명은 국적별 외래어 표기법에 맞춰 직접 음역했습니다(`data/names_ko_*.txt`). 원어 이름도 함께 저장해 검색에 씁니다.
- 트랜스퍼마크트에는 능력치가 없으므로 **OVR과 세부 능력치는 시장 가치·나이·세부 포지션·키로 추정**하고, **지난 시즌 실제 기록(출전·골·도움·카드·출전 시간, `python3 tools/fetch_tm_stats.py`)으로 장단점을 보정**합니다. 포지션 평균보다 골이 많으면 슈팅, 도움이 많으면 패스·시야, 카드가 많으면 몸싸움·적극성이 오르고 OVR은 그대로입니다. 주발은 역할 자동 배정(반대발 윙어 → 인사이드 포워드 등)에 쓰입니다 (`src/world.js`의 `ovrFromValue`). 시장 가치가 없는 선수는 리그 하위권 가치로 추정합니다.
- 유니폼 색은 엠블럼에서 자동 추출하고, 엠블럼과 홈 유니폼 색이 다른 구단은 직접 보정했습니다 (`tools/build_data.js`).
- 선수 사진과 엠블럼의 저작권은 트랜스퍼마크트와 각 권리자에게 있습니다. 개인 학습·비상업 용도로만 쓰고, 공개 배포하려면 사용 허가를 받아야 합니다.

## 주요 기능

- **실시간 2D 경기**: 위치 선정, 패스·드리블·슈팅 판단, 압박과 대인 마크, 오프사이드 라인, 크로스·코너킥·페널티킥, 파울과 카드, 부상. 1·2·4·8배속과 하이라이트 모드, 즉시 전술 변경, 교체 5명, 점유율·슈팅·xG·경기 흐름 그래프, 공을 가진 선수의 사진 표시, 하프타임 일시정지와 후반 진영 교체.
- **일정**: 하루 단위 진행(리그는 토요일, 컵은 수요일). 날마다 훈련·회복, 화·목 이적시장 활동, 일요일 재정 정산. 경기 전날은 회복 훈련.
- **전술**: 풋볼 매니저식 팀 지시 17가지(공격 시 8 · 수비 시 6 · 전환 3)와 프리셋 8종(게겐프레스, 티키타카, 수직 티키타카, 측면 공격, 롱볼, 유동적 역습, 텐백, 균형). 모든 지시는 엔진의 위치 선정·판단·압박·태클 계산에 직접 들어갑니다(`node tools/tactic-test.js`로 효과 확인).
- **선수 역할과 임무 (FM식)**: 43가지 역할(인버티드 윙백, 볼 플레잉 디펜더, 하프백, 레지스타, 메짤라, 인사이드 포워드, 폴스 나인, 타깃맨, 스위퍼 키퍼 등)과 수비·지원·공격 임무. 역할마다 공격/수비 시 위치, 침투, 패스·슈팅·드리블 성향, 압박 가담이 엔진에서 달라집니다. 선수 능력에 맞춘 자동 배정과 역할 적합도 별점.
- **수비 시 포메이션**: 공격 시와 다른 대형으로 수비(예: 4-3-3 → 4-1-4-1). 경기 중에도 바꿀 수 있습니다. 포메이션 숙련도는 쓸수록, 전술 훈련으로 올라가고 낮으면 경기력이 조금 떨어집니다.
- **FM 느낌**: 받은 편지함(어시스턴트 매니저의 상대 분석, 스카우트 보강 추천, 의료팀·단장·구단주 메시지), 화면 오른쪽 아래 '계속' 버튼, 1~20 세부 능력치(기술·정신·신체, 골키퍼는 골키핑)와 역할 핵심 능력치 강조, 경기 전·하프타임 팀 토크(선수별 반응과 사기 변화가 경기력에 반영), 하이라이트 재생, 실시간 평점, FM 다크 테마.
- **유럽 대항전**: UEFA 챔피언스리그·유로파리그(각 16팀). 5대 리그 상위권이 출전권을 얻고(첫 시즌은 전력순, 이후 리그 최종 순위), 4개 조 조별리그 → 8강·4강 홈 앤드 어웨이(합산, 동점이면 승부차기) → 단판 결승. 리그 경기 사이 화요일에 열리고, 출전·승리·라운드 진출 상금과 우승 트로피·업적이 있습니다.
- **경기 분석**: 직접 지휘한 경기마다 슈팅 지도(xG 크기, 골·유효·빗나감 구분), 패스 연결망(평균 위치와 패스 수), 선수별 히트맵, 선수 기록표, 시즌 경기별 xG 추세. 경기 결과 화면과 홈의 '지난 경기'에서 열 수 있습니다.
- **라이벌전**: 북런던 더비, 엘 클라시코, 밀라노 더비, 현대가 더비 등 실제 더비 38개. 홈 화면·경기 준비에 표시되고, 경기 중에는 태클·카드가 늘며 관중 열기를 중계합니다. 결과에 따라 선수단 사기·팬·구단주 신뢰도가 크게 움직이고 감독 부임 후 더비 전적이 쌓입니다.
- **시상**: 리그 라운드마다 베스트 11, 매달 이달의 선수·영플레이어·감독, 시즌 말 발롱도르(1~3위)·골든보이·유러피언 골든슈·리그 올해의 팀. 수상한 선수는 사기와 몸값이 오르고 선수 정보에 수상 내역이 남습니다.
- **중계 멘트**: 선제골·동점골·역전골·쐐기골·극장골·해트트릭, 헤더·중거리·페널티·단독 돌파 골, 침투 패스·크로스·태클·돌파·선방·코너킥, 시간대별 경기 흐름 요약 등 상황에 맞춘 해설 (경기 결과에는 영향을 주지 않는 별도 난수 사용).
- **현실감**: 관중 수에 따른 홈 어드밴티지(홈 승률 약 46%), 구단별 실제 감독 스타일과 주 포메이션(예: 맨시티 티키타카 4-3-3, 아틀레티코 역습 4-4-2, 아탈란타 대인 마크 3-4-3)으로 AI 전술 결정, 새 감독은 구단 전술을 물려받음. 엔진에 오프사이드(침투 타이밍·높은 라인 함정), 프리킥 직접 슈팅·측면 프리킥 크로스, 자책골, 골·교체·부상·카드로 정해지는 추가시간, 부상 정도(경미·중간·장기)를 추가.
- **커리어**: 리그마다 다른 라운드 수를 같은 주에 맞춰 6개 리그를 동시에 진행, 국내 컵(FA컵, 코파 델 레이, DFB 포칼 등), 구단주 목표와 신뢰도, 해임과 새 구단 제의.
- **선수단**: 사진이 들어간 라인업 편집기, 교체 명단 9명 직접 지정, 세부 포지션 적합도, 훈련 초점·강도, 성장과 노화·은퇴, 유스 승격, 계약 만료.
- **이적시장**: 한글·영문 이름, 구단, 국적으로 검색(여러 단어 조합 가능, 악센트 무시), 리그·나이·포지션·예산 필터, 가장 약한 선발 자리를 메울 추천 영입, 이적료 제안·역제안, 연봉 협상, 자유계약, 이적 리스트, AI 구단의 영입 제안과 역제안 협상(상대 최고액 안이면 합의, 조금 넘으면 최종 제안, 너무 높으면 결렬), 관심 선수.
- **구단 경영**: 리그 규모에 따른 중계권, 실제 수용 인원 기반 입장 수입, 스폰서, 주급, 시설 업그레이드. 금액은 유로(€)입니다.
- **기타**: 기자회견, 업적, 시즌 결산, gzip 압축 세이브 3슬롯, 라이트/다크 모드, PWA 설치.

## 실행

```bash
npm start            # http://localhost:8080
```

휴대폰에서 같은 와이파이로 `http://<컴퓨터 IP>:8080`에 접속한 뒤 "홈 화면에 추가"를 누르면 앱처럼 설치됩니다. 선수 사진과 엠블럼은 인터넷 연결이 있을 때 트랜스퍼마크트에서 불러옵니다.

## 안드로이드 APK

앱에는 선수마다 고화질 사진(트랜스퍼마크트 portrait/big → 240×312 webp)과 160px 로고가 들어갑니다. `python3 tools/build_assets.py --photos`로 `dist/photos`를 만든 뒤 `node tools/build.js`를 실행하면 `dist/app`에 포함됩니다 (없으면 스프라이트 사진 사용).

```bash
python3 tools/build_assets.py --sprites && node tools/build.js
ANDROID_BUILD_TOOLS=<build-tools 35 경로> ANDROID_JAR=<platforms/android-34/android.jar> tools/build_apk.sh
```

`dist/KickoffManager.apk`가 만들어집니다 (Gradle 없이 aapt2·d8·apksigner만 사용). 게임 파일과 선수 사진 스프라이트를 앱 안에 담아 오프라인에서도 동작하고, 글꼴만 인터넷이 있을 때 내려받습니다. 안드로이드 7.0(API 24) 이상에서 설치할 수 있어요. 서명 키(`android/release.keystore`)는 처음 빌드할 때 만들어지며 저장소에는 올리지 않습니다. 같은 키로 서명해야 업데이트 설치가 되니 잘 보관하세요.

## 데이터 갱신

```bash
pip install beautifulsoup4 pillow
python3 tools/fetch_transfermarkt.py 2026            # 리그·구단·선수 (요청 간격 1.5초, 약 3분)
python3 tools/fetch_transfermarkt.py --korean-names  # 한국 선수 한글 이름 (약 7분)
python3 tools/build_assets.py                        # 엠블럼에서 유니폼 색 추출
node tools/build_data.js                             # src/realdata.js 생성
```

내려받은 페이지는 `.tm-cache/`에 저장되어 다시 실행해도 같은 페이지를 요청하지 않습니다.

## 빌드와 테스트

```bash
npm run build        # dist/kickoff-manager.html (파일 하나로 실행)
python3 tools/build_assets.py --sprites && npm run build   # 외부 이미지를 못 쓰는 환경용 dist/artifact.html + dist/assets
npm run sim          # 경기 엔진 밸런스 확인
npm run season       # 시즌 전체 진행 확인
```

## 구조

| 파일 | 역할 |
| --- | --- |
| `src/realdata.js` | 트랜스퍼마크트 데이터 (자동 생성) |
| `src/data.js` | 포메이션, 세부 포지션 적합도, 리그 경제 규모, 구단 한글명 |
| `src/world.js` | 시장 가치 → 능력치 추정, 선수·구단 생성, 자동 라인업 |
| `src/engine.js` | 2D 경기 엔진 |
| `src/season.js` | 6개 리그 일정, 결과 반영, AI 경기 빠른 시뮬레이션, 이적, 재정, 훈련, 시즌 종료 |
| `src/render.js` | 캔버스 경기장 렌더러 |
| `src/ui.js` | 모든 화면과 입력 처리, 세이브 |
| `android/` | WebView 앱 껍데기 (매니페스트, 액티비티, 아이콘) |
| `tools/` | 데이터 수집, 에셋 처리, 밸런스 테스트, 번들러, APK 빌드 |
