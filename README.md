# 별똥별 피하기 (Star Dodger)

모바일 브라우저용 HTML5 캐주얼 게임입니다. 설치 없이 `index.html` 하나로 동작합니다.

## 플레이 방법
- 화면 아무 곳이나 드래그 → 우주선 이동 (손가락이 우주선을 가리지 않도록 상대 이동)
- 떨어지는 별똥별을 피하세요. 시간이 갈수록 빨라집니다.
- 🟡 코인: +10점 · 🔵 보호막: 5초 무적 · 🟣 슬로우: 4초간 별똥별 감속
- PC: 방향키/WASD 이동, `P`/`Esc` 일시정지, `Space` 시작

## 실행
`index.html`을 브라우저로 열거나, 로컬 서버로 띄워 휴대폰에서 접속하세요.

```bash
python3 -m http.server 8000
# 같은 Wi-Fi의 휴대폰에서 http://<PC-IP>:8000 접속
```

GitHub Pages를 켜면 바로 휴대폰에서 플레이할 수 있습니다.
