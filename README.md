# 머니모아 (MoneyMoa)

은행·카드·간편결제 앱의 **입출금 알림을 실시간으로 읽어** 한 곳에 모아 주는 안드로이드 가계부 앱입니다.
모든 데이터는 휴대폰 안(로컬 DB)에만 저장되고 외부로 전송되지 않습니다.

## 동작 방식
1. `NotificationListenerService`가 은행 앱 푸시와 문자 앱 알림을 받습니다.
2. `TransactionParser`가 문장에서 기관·입금/출금·금액·잔액·사용처를 뽑습니다.
   - 금융기관 이름이 확인되고, 입출금 키워드와 금액이 모두 있어야 거래로 인정
   - 광고·인증번호·출금예정·승인거절 문장은 무시
   - 카드 승인취소는 수입(환불)으로 처리
3. Room DB에 저장하면 화면이 즉시 갱신됩니다.
   - 같은 거래가 푸시+문자, 체크카드 승인+계좌 출금으로 두 번 오면 3분 안의 같은 금액은 하나로 합칩니다.

화면: 월별 수입/지출/합계, 날짜별 내역, 직접 추가(문자 붙여넣기로 자동 채우기), 길게 눌러 삭제.

## 빌드 & 설치
Android Studio로 열거나:
```bash
./gradlew assembleDebug        # app/build/outputs/apk/debug/app-debug.apk
./gradlew testDebugUnitTest    # 알림 문장 파서 테스트
```

## 처음 실행할 때
1. 앱의 **권한 켜기** → '머니모아 입출금 알림 수집' 허용
2. APK를 직접 설치했다면 Android 13+에서 스위치가 회색일 수 있습니다:
   설정 → 앱 → 머니모아 → 오른쪽 위 ⋮ → **제한된 설정 허용** 후 다시 켜기
3. 은행 앱에서 입출금 **푸시 알림**(또는 문자 알림)이 켜져 있어야 합니다.

## 한계
- 안드로이드 전용입니다 (iOS는 다른 앱의 알림을 읽을 수 없음).
- 알림이 오기 전의 과거 내역은 가져오지 못합니다.
- 은행마다 문구가 달라 인식 못 하는 형식이 있을 수 있습니다. 그런 문장은
  `app/src/test/.../TransactionParserTest.kt`에 예시로 추가하고 파서를 보완하면 됩니다.
