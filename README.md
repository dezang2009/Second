# 킥오프 매니저

모바일에서 즐기는 축구 감독 게임입니다. 텍스트 중계 위주의 매니저 게임을 한 단계 발전시켜, **22명의 선수가 실제로 움직이는 2D 경기 엔진**을 중심에 두었습니다.

## 주요 기능

- **실시간 2D 경기**: 선수마다 능력치·체력·역할에 따라 위치를 잡고, 공을 가진 선수는 패스·드리블·슈팅을 스스로 판단합니다. 압박, 대인 마크, 오프사이드 라인, 크로스·코너킥·페널티킥, 파울과 카드, 부상까지 엔진 안에서 일어납니다.
- **경기 중 개입**: 1·2·4·8배속, 포메이션과 전술 즉시 변경, 체력을 보면서 교체(최대 5명), 점유율·슈팅·xG 같은 실시간 기록과 경기 흐름 그래프.
- **커리어**: 가상 구단 32개, 1·2부 승강제(3팀 승강), 32강 단판 컵 대회, 구단주 목표와 신뢰도, 해임과 새 구단 제의.
- **선수단 관리**: 라인업 편집기(자리를 눌러 교체), 역할 적합도에 따른 능력치 보정, 훈련 초점·강도, 유망주 성장과 노화·은퇴, 유스 승격.
- **이적시장**: 이적료 제안·역제안, 연봉 협상, 자유계약, 이적 리스트, AI 구단의 영입 제안, 관심 선수 목록.
- **구단 경영**: 입장 수입·중계권·상품 판매·주급, 훈련장·유스 아카데미·경기장 업그레이드.
- **기타**: 경기 후 기자회견(선택에 따라 사기·신뢰도 변화), 업적, 시즌 결산, 3개의 세이브 슬롯(브라우저 저장소), PWA 설치와 오프라인 플레이.

## 실행

빌드 과정 없이 바로 실행됩니다.

```bash
npm start            # python3 -m http.server 8080 → http://localhost:8080
```

휴대폰에서 같은 와이파이로 `http://<컴퓨터 IP>:8080`에 접속한 뒤 "홈 화면에 추가"를 하면 앱처럼 설치됩니다.

파일 하나로 묶은 버전이 필요하면:

```bash
npm run build        # dist/kickoff-manager.html (더블클릭으로 실행 가능)
```

## 구조

| 파일 | 역할 |
| --- | --- |
| `src/util.js` | 시드 난수, 수학 함수, 금액·조사 포맷 |
| `src/data.js` | 구단, 이름, 포메이션, 역할 적합도 |
| `src/world.js` | 선수·구단 생성, OVR·가치·주급 계산, 자동 라인업 |
| `src/engine.js` | 2D 경기 엔진 (위치 선정, 판단, 공 물리, 태클·파울, 교체, 평점) |
| `src/season.js` | 일정, 결과 반영, AI 경기 빠른 시뮬레이션, 이적, 재정, 훈련, 시즌 종료 |
| `src/render.js` | 캔버스 경기장 렌더러 |
| `src/ui.js` | 모든 화면과 입력 처리 |
| `tools/` | 밸런스 테스트(`npm run sim`, `npm run season`)와 번들러 |

사용자 경기는 2D 엔진으로, 나머지 AI 경기는 엔진 결과에 맞춰 보정한 빠른 확률 모델로 계산합니다.
